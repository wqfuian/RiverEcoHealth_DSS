# 河湖岸线生态健康诊断辅助决策支持系统

WebGIS-based River Shoreline Eco-Health Diagnosis & Decision Support System

## 功能特点

- 🗺️ 三级岸线分类可视化
- 🩺 13指标AHP-FCE健康诊断
- 💊 智能修复策略推荐
- 📊 多时相对比分析
- 📄 PDF诊断报告导出

## 快速开始

### 本地运行

```bash
# 后端
cd backend_node
npm install
npm start

# 前端
cd frontend
npm install
npm run dev
```

### 在线部署

参见 [DEPLOYMENT.md](./DEPLOYMENT.md)

## 技术栈

- **前端**: Vue 3 + Vite + Tailwind CSS + OpenLayers + ECharts
- **后端**: Node.js + Express
