# Project Worklog — RiverEcoHealth DSS

## Purpose

保存系统开发过程中有价值但尚未正式固化的产品/科学/管理决策，避免换会话后重新讨论指标体系、架构和部署选择。

状态：`WORKING / PARKED / REJECTED / ACCEPTED-ELSEWHERE`。

## 每次重要讨论记录

- 要解决的用户/管理问题；
- 影响的是前端、后端、数据、指标体系还是部署；
- 当前实现与期望行为；
- 若涉及生态健康评价：科学依据、权重/阈值来源和不确定性；
- 备选方案及为什么采用/放弃；
- 下一步验证；
- 当前状态。

正式代码事实以 main/精确 commit 为准；部署事实以实际部署配置/运行结果为准。本日志不替代代码或科学验证。
